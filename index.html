Tentang Project

Project ini membahas penerapan dasar jaringan komputer menggunakan kabel UTP dan konektor RJ45. Materi meliputi proses penyusunan kabel LAN, pemasangan konektor RJ45, pengujian menggunakan LAN Tester, hingga menghubungkan dua laptop secara langsung.


Selain itu, website ini menjelaskan bagaimana melakukan konfigurasi jaringan sederhana dan sharing file antara laptop 1 dan laptop 2 menggunakan kabel LAN.

01 • Dasar

Apa Itu Kabel LAN?

Pengertian dan fungsi kabel LAN dalam jaringan komputer.

🌐

LAN / Local Area Network

LAN atau Local Area Network merupakan jaringan komputer yang digunakan untuk menghubungkan beberapa perangkat dalam area terbatas, seperti rumah, laboratorium, sekolah, kantor, atau kampus.


Salah satu media transmisi yang sering digunakan pada jaringan LAN adalah kabel UTP yang dipasang menggunakan konektor RJ45. Kabel tersebut dapat digunakan untuk menghubungkan komputer, laptop, switch, router, dan perangkat jaringan lainnya.

Alat & Bahan

Peralatan yang digunakan dalam pembuatan kabel LAN.

Digunakan untuk menguji apakah susunan kabel LAN sudah benar dan terhubung dengan baik.

04 • Praktik

Cara Merangkai Kabel LAN

Langkah-langkah membuat kabel LAN menggunakan RJ45.

1

Siapkan Kabel UTP

Ukur dan potong kabel UTP sesuai panjang yang dibutuhkan. Sisakan sedikit bagian kabel untuk proses pemasangan konektor.

2

Kupas Kabel

Gunakan cable stripper atau bagian pengupas pada tang crimping untuk membuka pelindung luar kabel.

3

Susun Kabel

Pisahkan kabel-kabel kecil di dalam UTP kemudian susun sesuai standar T-568A atau T-568B.

4

Masukkan ke RJ45

Setelah urutan warna benar, rapikan ujung kabel dan masukkan seluruh kabel ke dalam konektor RJ45.

5

Crimping

Masukkan RJ45 ke tang crimping kemudian tekan dengan kuat sampai pin konektor menjepit kabel.

6

Uji dengan LAN Tester

Hubungkan kedua ujung kabel ke LAN Tester. Periksa lampu indikator untuk memastikan susunan kabel sesuai.

05 • Koneksi

Menghubungkan 2 Laptop

Menghubungkan laptop 1 dan laptop 2 menggunakan kabel LAN.

💻

Laptop 1

IP: 192.168.1.1

💻

Laptop 2

IP: 192.168.1.2

Konfigurasi IP Address

  1. Hubungkan kedua laptop menggunakan kabel LAN.
  2. Buka Settings → Network & Internet → Ethernet.
  3. Atur IPv4 Laptop 1 menjadi: 192.168.1.1
  4. Atur IPv4 Laptop 2 menjadi: 192.168.1.2
  5. Gunakan Subnet Mask: 255.255.255.0
  6. Gateway tidak wajib diisi untuk koneksi langsung antar-laptop.
Laptop 1 → IP Address: 192.168.1.1
Laptop 2 → IP Address: 192.168.1.2
Subnet Mask → 255.255.255.0

Tes koneksi menggunakan Command Prompt:

ping 192.168.1.2
06 • File Sharing

Sharing File Antar Laptop

Cara membagikan file dari laptop 1 ke laptop 2.

💻 Laptop 1 — Pemilik File

  1. Pilih folder yang ingin dibagikan.
  2. Klik kanan folder → Properties.
  3. Pilih tab Sharing.
  4. Klik Advanced Sharing.
  5. Centang Share this folder.
  6. Klik Apply lalu OK.
  7. Pastikan Network Discovery dan File Sharing diizinkan pada jaringan yang digunakan.

💻 Laptop 2 — Penerima File

  1. Tekan Windows + R.
  2. Masukkan alamat: \\192.168.1.1
  3. Tekan Enter.
  4. Folder yang dibagikan dari Laptop 1 akan muncul.
  5. Buka folder tersebut dan salin file yang diperlukan.
Tips: Pastikan kedua laptop berada pada jaringan yang sama, IP Address tidak sama, dan Windows Firewall/Network Profile mengizinkan komunikasi File and Printer Sharing.

08 • Penutup

Kesimpulan

Kabel LAN merupakan salah satu media yang dapat digunakan untuk membangun jaringan komputer. Dalam pembuatannya, kabel UTP disusun berdasarkan standar warna tertentu kemudian dipasang pada konektor RJ45 menggunakan tang crimping.


Setelah kabel selesai dibuat, LAN Tester dapat digunakan untuk memastikan koneksi setiap pin. Kabel tersebut kemudian dapat digunakan untuk menghubungkan dua laptop dan melakukan pertukaran data melalui fitur file sharing.
