1. Peralatan & Bahan Praktikum

Komponen utama yang dibutuhkan dalam perangkaian kabel LAN dan koneksi jaringan.

Kabel UTP Cat 5e/6

Kabel jaringan yang berisi 8 kawat tembaga terpilin berpasangan untuk mendistribusikan data.

Konektor RJ45

Konektor modular 8-pin yang dipasang pada ujung kabel UTP agar terhubung ke port LAN PC.

Tang Crimping

Alat untuk mengupas pelindung luar, memotong kawat, dan mengunci pin tembaga RJ45 ke kabel UTP.

LAN Tester

Alat penguji keterhubungan sinyal elektrik 8-pin pada kedua ujung kabel secara bertahap via indikator LED.

3. Setup IP Statis & Sharing File Dual PC

Konfigurasi PC, pengujian CMD ping, dan pembagian folder pada File Explorer.

1

Konfigurasi IP Address Statis

Hubungkan 2 laptop menggunakan kabel LAN. Atur IP Statis kedua laptop dalam segmen subnet yang sama.

# Laptop A
IP: 192.168.1.1
Subnet: 255.255.255.0
# Laptop B
IP: 192.168.1.2
Subnet: 255.255.255.0
2

Uji Koneksi (CMD Ping)

Buka Command Prompt pada Laptop A untuk memastikan koneksi data berjalan lancar.

C:\> ping 192.168.1.2
Pinging 192.168.1.2 with 32 bytes...
Reply from 192.168.1.2: bytes=32 time<1ms TTL=128
Packets: Sent = 4, Received = 4, Lost = 0 (0% loss)
3

Akses Folder Terbagi

Aktifkan "File Sharing" di Windows Network Center, lalu bagikan folder bertipe 'Everyone'.

// Ketik di File Explorer Laptop B:
\\192.168.1.1
*Folder terbagi dari Laptop A dapat langsung diakses.
